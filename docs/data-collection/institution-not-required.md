# 기관 심의 비대상 운영 기록

- 접수일: 2026-11-11 (KST).
- 확인 경로: 프로젝트 사용자가 학교·기관에 직접 확인한 결과를 이 작업 요청으로 전달했다. 전화/이메일 등 세부 연락 방식과 실제 확인일은 제공되지 않았다.
- 전달받은 판단: 개발팀원 A/B/C 3명이 자신의 웹 탐색 행동 데이터를 수집해 AI 모델 학습·평가에 활용하는 본 캡스톤 프로젝트에는 별도의 기관 심의·승인 절차가 필요하지 않다는 안내를 받았다.
- 반영: institution.decision=NOT_REQUIRED. REQUIRED_SATISFIED(필요한 절차를 이행한 상태) 또는 심의면제 승인 문서가 발급된 상태로 해석하지 않는다.
- 범위: 기존 3인·20목표·160세션·15개 공개 사이트·메타데이터 최소화 운영 정책. 참여자별 본인 동의 및 철회·민감정보·사이트·인증·Build/Session Scope 검사는 계속 적용한다.
- 확인되지 않은 담당자 이름·기관 문서 번호·승인서·서명을 생성하지 않았다. 이 기록은 사용자가 전달한 판단의 운영 출처이며 기관이 발급한 공식 문서가 아니다.

추가 records.json·policy-prepare·관리자 승인·정책 발행은 필요 없다. 이 기록은 저장소에 포함되며 setup은 기존 정책 스키마의 evidenceRef로 참조한다. 향후 실제 확인일/세부 확인 경로가 제공되면 이 문서의 해당 항목에 사실만 보완할 수 있다. 이 보완을 기본 설치의 추가 조건으로 요구하지 않는다.
