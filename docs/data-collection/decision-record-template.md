# 비공개 실제 기록 입력 양식

이 파일은 빈 양식이다. 실제 승인/동의가 아니다. 비공개 위치로 복사해서 실제 담당자가 작성한다. 공개 Git에 실명·서명·연락·기관 원문을 올리지 않는다.

- 기록 ID / 작성자 역할 / 작성일 / 실제 확인 방법:
- 대상 정책 파일 버전 및 SHA-256:
- A/B/C 각각의 실제 정책 확인·결의 일시/증거 위치:
- GOAL-001~020 원문·완료 기준·4시나리오·160배정의 전체 확인자/일시:
- 목표별 10개 의미 있는 공개 페이지 목록·시나리오 흐름 검토 결과:
- 사이트별 exact origin/path·제외 경로·공개성·이용 조건 근거/필요 허가·Chrome 검사:
- 기관 판단 담당자/기관 역할·연락 경로·확인일·실제 문서·필요 절차 완료 또는 비적용 판단:
- 최종 평가일(미정이면 확정 담당/확인 시점), +90일 삭제 예정일:
- PC 소유자 A/B/C·통합 담당자의 실제 연락·사본별 실행/확인 책임:
- 원본 DB/Chrome/Export/통합/백업/파생·학습용 사본 위치·보유자·회수 연락·삭제 방법:
- 철회 통보·이용 중지·격리·사본 회수/삭제 확인 기록·예외/잔여 사본 처리:
- 개시 책임자·승인일·정책 유효 기간·승인 범위·실제 파일럿 확인:

참여자 동의는 이 문서로 대신하지 않는다. 각자가 Extension에서 직접 동의한다. 담당자는 실제 완성 문서의 SHA를 records.json에 입력한다. macOS는 `shasum -a 256 FILE`, Windows는 `Get-FileHash FILE -Algorithm SHA256`을 사용한다. 미확인 항목이 남으면 confirmedByRecordOwner를 false로 유지한다.
